# CodeAlpha_Image_gallery

A responsive and interactive Image Gallery Web Application developed as part of my CodeAlpha Internship. The project provides a simple and attractive way to display and browse a collection of images.

 PROJECT OVERVIEW

The CodeAlpha Image Gallery is a front-end web project created using HTML, CSS, and JavaScript. It allows users to view images in an organized gallery layout and interact with the displayed images.

This project helped me improve my understanding of web page design, responsive layouts, and JavaScript-based interactivity.

 FEATURES

-  Attractive image gallery layout
-  Easy image browsing
-  Previous and next image navigation
-  Image viewing functionality
-  Responsive design
-  Clean and user-friendly interface
-  Interactive JavaScript functionality

TECHNOLOGIES USED

- HTML5 – Structure of the gallery
- CSS3 – Styling, layout, and responsiveness
- JavaScript – Image navigation and interactivity
